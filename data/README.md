# Data

The repository ships **no personal or proprietary credit records**. The default training path creates a deterministic synthetic development population that encodes realistic nonlinear risk relationships and is suitable for demonstrating the engineering pipeline.

For serious experimentation, place an appropriately licensed credit-performance dataset in `data/raw/` and adapt `model/train.py` to its schema. Suitable research sources include the FICO Explainable ML Challenge/HELOC dataset or another dataset whose redistribution and use terms you have reviewed.

Do not use the bundled model for real lending decisions.
